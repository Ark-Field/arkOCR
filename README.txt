==================================================
 🛠️ 業務お助けツールボックス (OCR & PDF Custom Gatchanko)
==================================================

日常の事務作業（文字起こし・PDFのレイアウト調整など）をブラウザ上で
手軽に行うために作成した、自分専用のStreamlit製Webアプリケーションです。

---

## 📌 主な機能

1. 📄 OCR文字起こし (画像・PDF・表対応)
   - 画像（PNG, JPG）およびPDFファイルをアップロードしてテキストを抽出します。
   - グレースケール前処理による認識率向上や、表組み・レイアウトに特化した
     Tesseractの解析モード（PSM 6 / PSM 4）の切り替えに対応しています。

2. ✂️ カスタムトリミング＆ガッチャンコ
   - 2つのPDF（1ページ目）をアップロードし、それぞれ「上から / 下から」
     何パーセントを残すかをスライダーで自由に指定して切り抜きます。
   - 指定したA4用紙の向き（縦・横）と配置比率（50/50, 40/60, 60/40）に
     合わせて1枚のPDFに綺麗に統合し、ダウンロードできます。

---

## 💻 動作環境・必要要件

- **OS**: Windows
- **言語**: Python 3.x
- **主要ライブラリ**:
  - Streamlit (UIフレームワーク)
  - PyMuPDF / fitz (PDF処理・画像変換)
  - Pillow (画像処理)
  - pytesseract (OCRラッパー)
- **外部エンジン**:
  - **Tesseract OCR** (Windows本体へのインストールおよび日本語言語データが必要)
    - ダウンロード元: https://github.com/UB-Mannheim/tesseract/wiki

---

## 🚀 起動方法

1. コマンドプロンプト等でアプリのフォルダに移動します:
   > cd C:\arkOCR

2. バッチファイルをダブルクリック、または以下のコマンドを実行します:
   > python -m streamlit run app.py

3. ブラウザが自動で立ち上がり、ツールを利用できます。
